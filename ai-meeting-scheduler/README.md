# AI Meeting Scheduler Bot

This project is an AI-powered bot that helps you schedule meetings.

## Features

- Natural language understanding to process meeting requests.
- Integration with calendar APIs to check availability and schedule meetings.

## Getting Started

To get started, clone the repository and install the dependencies:

```bash
git clone https://github.com/your-username/ai-meeting-scheduler.git
cd ai-meeting-scheduler
pip install -r requirements.txt
```

Then, run the bot:

```bash
python src/main.py
```
